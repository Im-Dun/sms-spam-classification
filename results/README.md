# Kết quả thực nghiệm

Các tệp trong thư mục này là kết quả được sinh bởi `src/train.py` và `src/evaluate.py`.

Sau khi thay đổi cấu hình pipeline, cần chạy lại theo thứ tự từ thư mục gốc:

```bash
python -m src.train
python -m src.evaluate
```

Không sử dụng các bảng/biểu đồ cũ làm kết quả chính thức nếu chúng được tạo từ phiên bản code trước khi thống nhất cấu hình tiền xử lý của bốn mô hình.
