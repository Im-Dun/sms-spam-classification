# Dataset

Đặt bộ SMS Spam Collection đã giải nén tại `data/SMSPSamCollection/`.

Mã nguồn tìm file dữ liệu tên `SMSSpamCollection` hoặc các file `.txt`/`.csv` phù hợp bên trong thư mục dữ liệu.

Nguồn dataset gốc: UCI Machine Learning Repository — SMS Spam Collection.
Trang tham khảo: https://archive.ics.uci.edu/dataset/228/sms+spam+collection

Không đưa file dữ liệu lên GitHub nếu không cần thiết hoặc nếu kích thước/chính sách môn học không cho phép. Trong trường hợp không commit dataset, hãy giữ hướng dẫn tải và đặt dữ liệu ở đây.
